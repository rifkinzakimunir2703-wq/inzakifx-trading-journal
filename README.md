# InzakiFX Trading Journal — MVP

## Fitur
- Dashboard statistik
- Total trade
- Win rate
- Net P/L
- Profit factor
- Maximum drawdown
- Equity curve
- Riwayat trade
- Search symbol/strategi
- Catatan trade
- Export CSV
- Responsive untuk HP
- Tidak membutuhkan backend untuk MVP

## Cara menjalankan
Buka `index.html` di browser.

## Cara upload gratis
Pilihan termudah:
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `app.js`.
3. Aktifkan GitHub Pages pada repository.
4. Website bisa diakses melalui alamat GitHub Pages.

Alternatif: upload folder ini ke Vercel atau Cloudflare Pages.

## Catatan data
Versi MVP menyimpan data di `localStorage` browser. Artinya data hanya tersimpan pada browser/perangkat yang digunakan.
